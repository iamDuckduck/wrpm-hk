# Stitch exports

Export the WRPM Stitch design-system summary and approved screens here before running the Open Design audit.

Required artifacts:

- `design-tokens.md` with colors, typography, spacing, borders, radii, elevation, and breakpoints
- Approved desktop and mobile screens
- Navigation, card, table, carousel, loading, empty, error, focus, and hover states used by WRPM

Use `approved`, `draft`, or `reference` in filenames when multiple versions exist.
