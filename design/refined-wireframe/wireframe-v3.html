WRPM Competition / Competition Season flow wireframe

Refined route and interaction wireframe for dynamic Competitions navigation, Competition Season overviews, and completed match results. Home and Member surfaces remain unchanged while the selected-season context stays explicit.

Flow map Navigation popup Member list Member detail Competition Season overview Historical state Match details States

1. Route flow map

Existing routes only
Home route Existing homepage — unchanged. Compact entry node only. / -> nav popup Member list Active member cards from existing member list query. /members Member detail Profile, intro, biography, links, not-found fallback. /members/[slug] Competition Season overview Latest/ongoing season for the selected Competition. /competitions/[competitionSlug] Competition Season Same overview template with a specifically selected season. /competitions/[competitionSlug]/[seasonSlug]
Competitions dropdown Dynamic public navigation → Latest Competition Season /competitions/[competitionSlug] → Selected Competition Season /competitions/[competitionSlug]/[seasonSlug] → Completed matches /competitions/[competitionSlug]/[seasonSlug]/matches

Each Competition opens its latest/ongoing Competition Season. Season selector links stay within overview pages; only View match details enters the separate completed-results screen.

Wireframe data relationship
Competition Localized name/title, slug, introduction, description.
Competition Season References exactly one Competition; title, slug, status, start/end dates, participants.
Match + derived ranking Match references one Competition Season; ranking uses completed matches from the selected season only.
